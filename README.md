# automl_binder

A minimal Binder-ready demo for running FLAML AutoML on a user-uploaded CSV file.

## Run on Binder

Open this notebook in Binder:

`https://mybinder.org/v2/gh/chubbd/automl_binder/HEAD?labpath=notebooks/flaml_csv_upload_demo.ipynb`

## Local use

Install dependencies:

```bash
pip install -r requirements.txt
```

Then open and run:

`notebooks/flaml_csv_upload_demo.ipynb`
